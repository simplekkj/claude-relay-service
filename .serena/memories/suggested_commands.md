# Suggested Commands

## Setup
- `make setup` (copies config examples and bootstraps)

## Dev
- `npm run dev` or `make dev` (API server with nodemon)

## Prod
- `npm start` or `make start` (runs lint first)

## Tests
- `npm test`
- `npm test -- --coverage`

## Web Admin
- `npm run build:web`

## Docker
- `npm run docker:up` (Docker Compose with Redis)

## Useful system commands (macOS/Darwin)
- `ls`, `cd`, `pwd`, `rg`, `find`, `git status`, `git diff`
